# Getting started

Start here to build or run the code, create a small LUND sample, and check its output. A checkout is a local copy of the Git repository. Use a local development checkout for editing and a separate ifarm checkout for production commands.

1. Check [dependencies and choose an execution environment](installation.md).
2. Run the [quickstart](quickstart.md).
3. [Learn what each output directory means](outputs.md).
4. [Create LUND files](../create-lund/index.md), choosing the uniform or physical guide for your input.
5. [Submit simulation](../submit-simulation/index.md), then follow its job-verification steps.

The workflow overviews give the reading order within each workflow. Use configuration references when changing a setting, and tutorials when you need complete copyable commands. Contributors should continue with the [developer reading path](../development/index.md).
