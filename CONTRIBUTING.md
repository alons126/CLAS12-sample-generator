# Contributing

The complete contribution guide is in the generated Wiki source at [`docs/development/contributing.md`](docs/development/contributing.md). Follow the [developer reading order](docs/development/index.md) and read the user guide for the workflow you intend to change.

Code, command-line help, checked-in profiles, tutorials, and Wiki pages are one contract. Update and validate every affected layer in the same change. Do not edit generated Wiki pages directly; edit the repository sources and let the publication workflow rebuild the Wiki.
