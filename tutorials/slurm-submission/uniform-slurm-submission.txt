# Corresponding creation commands: uniform-lund-creation.txt
# Run on ifarm after each matching manifest is published. These examples submit the
# first 5 of the 40 files produced by a 1,000,000-event run at 25,000 events per file.
# The manifest supplies metadata and the event limit. Submission defaults to GEMC 5.14
# and COATJAVA 10.0.7. Remove --execute to preview. Execution replaces simulation output
# but preserves LUND input.

#########################################################################################
# Preview the 100-event quickstart run: one LUND file, not the five-file selection below
#########################################################################################

source run.csh \
    --workflow submit \
    --lund-dir /path/to/quickstart-output/Uniform__1e__5986MeV/lundfiles
